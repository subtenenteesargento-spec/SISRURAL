SISRURAL V11.1 DEV – FOTOS DE REFERÊNCIA DA PROPRIEDADE / CLOUDINARY

ALTERAÇÕES
- Até 2 fotos opcionais no cadastro da propriedade.
- Compressão automática no aparelho (máx. 1280 px; JPEG otimizado).
- Upload das fotos para Cloudinary usando o preset sem assinatura "sisrural_propriedades".
- Cloud name utilizado: bgbxcibj.
- Pasta configurada no Cloudinary: SISRURAL/PROPRIEDADES.
- Firestore guarda apenas URLs/metadados das fotos; as imagens não são gravadas dentro do Firestore.
- Se estiver offline ou falhar o upload, as fotos ficam em IndexedDB aguardando sincronização automática.
- Painel do Comandante identifica propriedades com fotos e permite abrir as imagens pelo SISRURAL.
- Relatório de visitas mantém o link "Ver fotos" quando a propriedade possui imagens.
- Visitas permanecem sem fotos.
- Compatibilidade mantida para leitura de eventuais registros antigos com fotosPaths no Firebase Storage.

SEGURANÇA / OBSERVAÇÃO
- Nenhuma API Secret da Cloudinary foi adicionada ao código.
- O upload usa somente Cloud Name + Upload Preset unsigned, adequados ao frontend estático.
- As URLs secure_url do Cloudinary são URLs de entrega; quem obtiver a URL direta poderá acessar a imagem. O SISRURAL não exibe essas URLs diretamente no relatório e mantém a abertura pelo fluxo autenticado do aplicativo, mas isso não equivale a armazenamento privado.
- Para armazenamento estritamente privado seria necessário backend com assinatura/autenticação de entrega.
